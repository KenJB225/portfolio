Aegis-Dry Smart Laundry System

Aegis-Dry is a smart laundry protection system that uses rain forecasts and a configurable rain-probability threshold to decide when its connected drying device should retract or extend. Our team is building a web-based admin panel to monitor the system and manage its users and devices.

Current features

  • Weather-based DOCK or EXTEND instructions for the device.
  • Sensor data for rain, temperature, humidity, moisture, battery, and signal.
  • Admin tools for user and device management, activity logs, rain-threshold settings, and manual overrides.

Technology: Next.js, React, Supabase Auth and Edge Functions, and the OpenWeatherMap API.
